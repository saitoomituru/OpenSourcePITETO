# OpenSourcePITETO 実験ノート棚

ここは、README正本へ入る前の再現、改良、失敗、Recovery、生活兵站観測を保存する場所です。

## ノートを追加する

1. [`AGENTS.md`](AGENTS.md)を読む
2. [`TEMPLATE.ja.md`](TEMPLATE.ja.md)を日時付きの名前へ複製する
3. 元レシピとの差、観測、失敗、内観メモ／ポエム、未解決を分けて記入する
4. 写真を追加する場合は公開情報とExif/GPSを確認する
5. READMEへ反映したい内容は「昇格候補」へ書き、ノート作成と正本変更を分ける

例:

```bash
cp note/TEMPLATE.ja.md note/20260724-1200__品種違い再現試験.ja.md
```

ノートは成功報告専用ではありません。フニャった、焦げた、粉が落ちた、時間を測り忘れた、腹が減って待てなかった等も、次の実験者が同じ穴へ落ちないための成果です。
